# adaptive-brightness

Демон для macOS: подстраивает яркость подсветки под то, насколько светлый контент
сейчас на экране. Тёмная IDE — ярче, светлый браузер — тусклее. На панелях XDR
умеет поднимать яркость выше 100%.

Правильную яркость задаёшь ты, рукой. Демон не решает за тебя — он двигает
подсветку **относительно** твоей точки и отходит в сторону, как только ты
берёшься за клавиши.

## Что умеет

- подстраивает яркость под содержимое экрана — плавно, без ступенек и рывков
- схватил клавиши посреди хода — мгновенно замирает и принимает твоё значение за
  новое правильное, пока контент заметно не сменится
- выше 100% на XDR: родные клавиши яркости просто едут дальше, до 160%
- молчит, пока идёт игра — по Game Mode и по списку приложений
- не трогает подсветку на спящем и заблокированном экране

## Требования

macOS 14+, Apple Silicon. Яркость выше 100% — только на панелях Liquid Retina XDR.

## Установка

```bash
./build.sh      # собирает .app-бандл в ~/Applications
./install.sh    # регистрирует в launchd, автозапуск при входе
```

При первом запуске macOS спросит разрешение на **запись экрана** — без него не
посчитать светлоту. Чтобы клавиши яркости работали выше 100%, нужен ещё
**Универсальный доступ**; демон запросит сам.

Снять всё: `./uninstall.sh`

## Как пользоваться

Никак — он просто работает. Не нравится текущая яркость — крутани клавишами,
демон примет это за новую точку отсчёта.

Упёрся в 100% и жмёшь «ярче» дальше — начинается буст до 160%. Обратно тем же
способом.

**Нажми «ярче» и «тусклее» одновременно** — адаптация выключится, и яркость
останется полностью твоей. Тем же аккордом включается обратно. Удобно на время
фильма: демон иначе поднимет яркость на тёмной сцене.

Выключатель переживает перезапуск демона и перезагрузку: решение принято руками,
отменять его молча неправильно. Текущее состояние видно в `status`.

```bash
adaptive-brightness toggle      # то же, что аккорд, если клавиш под рукой нет
adaptive-brightness status      # обе точки, цель, буст
adaptive-brightness boost 135   # буст из командной строки
adaptive-brightness reset       # пересобрать обе точки от текущей яркости
adaptive-brightness probe       # светлота экрана раз в секунду — для калибровки
```

## Настройка

Конфиг — `~/.config/adaptive-brightness/config.json`, образец лежит в
[`config.example.json`](config.example.json). Файла может не быть: тогда работают
дефолты. Пересборка после правки не нужна, достаточно перезапуска:

```bash
launchctl kickstart -k gui/$UID/com.geforester.adaptive-brightness
```

Главного в конфиге нет — **две яркости демон узнаёт от тебя, а не из файла**.
Выстави на тёмном экране ту, что нравится, переключись на светлый, выстави там
свою — и дальше он ходит ровно между этими двумя числами. Поправил одну —
вторая осталась как была. Посмотреть, что он запомнил, — `adaptive-brightness
status`:

```
Тёмный экран:     79%
Светлый экран:    48%
```

Из ручек обычно нужны две:

| ключ | что делает |
|---|---|
| `travelTime` | за сколько секунд яркость приходит к цели |
| `pauseApps` | префиксы bundle id, при которых яркость не трогать. `"com.codeweavers."` накрывает все игры под CrossOver |

Что считать тёмным экраном, а что светлым, задают `darkPoint` и `lightPoint`.
Подобрать их можно так: запусти `adaptive-brightness probe`, переключайся между
своими приложениями и запиши `luma` на самом тёмном и на самом светлом.

`span` остался только для самого первого запуска, когда ни одной точки ещё нет:
по нему демон прикидывает пару от текущей яркости. Первая же правка на тёмном
или светлом экране заменит свой конец настоящим, и дальше `span` ни на что не
влияет.

Остальные ключи разобраны в [INTERNALS.md](INTERNALS.md).

## Что важно знать

**Выключи системную автояркость.** Системные настройки → Дисплеи →
«Автоматически настраивать яркость». У MacBook свой датчик освещённости, который
крутит ту же подсветку; демон примет его правки за твои и запишет их в точку.

**Буст выше 100% не бесплатен.** HDR-видео при нём обрезается, батарея садится
заметно быстрее, панель греется — macOS сама сбросит яркость при перегреве.
Вечером Night Shift перезаписывает таблицу гаммы и буст на секунду проседает.

**На видео во весь экран демон реагирует как на контент** — тёмная сцена поднимет
яркость. Если мешает, крутани яркость рукой: демон замрёт и не полезет обратно,
пока картинка заметно не сменится.

## Диагностика

```bash
adaptive-brightness status
tail -f ~/.local/state/adaptive-brightness/daemon.log
launchctl kickstart -k gui/$UID/com.geforester.adaptive-brightness
```

Baseline уехал в странное место — `adaptive-brightness reset`.
